## Apa itu rust
ust adalah bahasa pemrograman sistem open-source yang berfokus pada kecepatan tinggi, keamanan memori, dan konkurensi.
Bahasa ini dirancang oleh Mozilla Research sebagai alternatif modern untuk C dan C++ tanpa menggunakan garbage collector.
Anda bisa mempelajari dokumentasi resminya langsung melalui [Situs Resmi Rust](https://rust-lang.org).

## Instalasi

melalui rustup:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

untuk termux (Android):

```bash
pkg install rust
```
